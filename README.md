# Menu Driven Console Bank Project

A simple console-based, menu-driven bank management application that lets users create, view, edit, and delete bank account records. This repository is intended as a small learning/demo project.

## Features

- Create new bank accounts with basic details (customer name, account number, balance, etc.).
- View a list of all accounts and inspect individual account details.
- Edit existing account information.
- Delete accounts.
- Simple numeric menu interface for use in the terminal/console.

## Getting Started

Follow these steps to run the project locally. The exact commands depend on the language of the implementation — check the repository source files for the entry point (for example, `main.c`, `Main.java`, or `main.py`).

### Prerequisites

- A compiler or interpreter for the language used in this repo (for example, gcc, Java JDK, or Python).
- A terminal or command prompt.

### Running the project (examples)

- If written in C:
  1. Compile: `gcc -o bank main.c` (replace `main.c` with the actual source file(s)).
  2. Run: `./bank`

- If written in Java:
  1. Compile: `javac Main.java` (replace `Main.java` with the actual entry file).
  2. Run: `java Main`

- If written in Python:
  1. Run: `python main.py` (replace `main.py` with the actual entry file).

If you are unsure which file to run, look for common entry filenames such as `main.c`, `Main.java`, `main.py`, or an obvious README or build script that documents the run command.

## Usage

1. Start the application from the terminal using the appropriate command for the project language.
2. Use the numeric menu choices to navigate (for example: 1 = Create Account, 2 = View Accounts, 3 = Edit Account, 4 = Delete Account, 0 = Exit).
3. Follow on-screen prompts to input or modify account information.
